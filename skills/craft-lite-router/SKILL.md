# Craft Lite Router

Load one primary method for the current phase; do not load the entire suite. The suite has one project framework and five practical methods.

- First-time project configuration → `craft-lite-setup`
- Unclear requirement or design → `craft-lite-discovery`
- Confirmed implementation or multi-step change → `craft-lite-build`
- Non-obvious bug, regression, flake or performance issue → `craft-lite-diagnose`
- Diff, branch or completed change review → `craft-lite-review`

A phase may lead to the next method in the same task. That is sequential progress, not a choice between competing workflows. Do not run discovery for an explicit tiny fix; do not code through an unresolved material decision.

State the chosen method, current authorization, and the next completion criterion, then read and execute only that method.
